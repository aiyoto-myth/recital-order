Other ways to paste

A spreadsheet or your studio software's export, one row per dancer in a routine. Extra columns are fine. A header row like Dancer, Class or First Name, Last Name, Class tells it which column is which.

First Name Last Name Class Ava Martinez Tiny Tots Ballet Mia Kim Tiny Tots Ballet

Names written "Last, First"? Put a semicolon between dancers: Jazz II: Martinez, Ava; Kim, Mia.

Blocks: the routine name on its own line, its dancers under it, an empty line between routines.

Write each dancer's name the same way every time. That is how it knows "Ava M" in ballet is the same girl as "Ava M" in jazz.

How the order is worked out

  1. For every dancer it counts the numbers between one of her routines and the next. Fewer than the rule (yours, or the one you set for her) is a quick change. Going into bows or a finale marked "no costume change" needs no time; coming out of it does.
  2. It tries thousands of orders a second and keeps the one with the fewest quick changes, then the fewest very tight ones. Back-to-back numbers count worst.
  3. Locked routines, the opener and the closer never move. "Early" stays in the first third, "late" in the last third, "Act 1 only" before the intermission.
  4. Once you have an order, building again keeps your arrangement and only moves what it must to fix quick changes. "Start over from scratch" throws it away.
  5. When zero quick changes is impossible, it says who can't fit and why. The backstage list then tells you who needs a helper.
